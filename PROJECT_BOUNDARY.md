# Project boundary

Leonardo Tales Constitution v1.1.1 governs internal project decisions.

Leonardo Tales Agent Control Plane v0.1.0 provides a control layer for accountable agent actions. It demonstrates scoped proposals, exact operator approval, Task accounting and inspection through one trusted foreground Linux process.

The project is affiliated with the Leonardo Tales Core governance domain for constitutional and governance purposes. Agent Control Plane is a separate open-source product that implements selected Core governance protocols. This affiliation grants no cross-project authority, access to private Core data, or authority over other repositories.

The host runs one registered synthetic action and one allowance unit per Task. The example uses local fixture IDs, synthetic identities, private Task state and a local handler. The host validates inputs, binds the caller and operator, derives policy facts and constrains the handler. Policy Engine evaluates those facts. Action Gateway owns allowance, admission, dispatch, authoritative execution receipts and holds.

Bound agents can propose, submit and inspect their own operations using the handles supplied by the host. The operator controls Task scope, exact approval and Task pause or resume. See [agent roles](AGENTS.md) and [permissions](PERMISSIONS.md).

Use a private Task directory and synthetic input. Private research records, credentials, real user data and external provider accounts fall outside the supported workflow. Stop on unclear authority, missing approval, a suspected disclosure, unsupported data, a stranded writer lock, or a Task binding mismatch. Inspect an uncertain execution and preserve its hold. Repository publication, broader access and external integrations require separate human approval.

Project governance applies to project decisions and contributions. Apache-2.0 governs downstream use of original product materials. CC BY 4.0 governs downstream use of the canonical Constitution.
