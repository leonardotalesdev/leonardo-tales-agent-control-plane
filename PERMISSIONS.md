# Permissions

Leonardo Tales Constitution v1.1.1 governs internal project decisions.

| Class | Local pilot scope |
|---|---|
| Read | Bound agents can inspect their own operation through their client. The operator can inspect the private Task evidence. |
| Draft | A bound agent may propose a validated synthetic action within its assigned Run. |
| Suggest | A bound actor can present a proposed action for operator review within the Task. |
| Modify | The trusted host persists Task state and access records. Gateway records allowance and execution updates. |
| Execute | Operator review and Gateway admission govern dispatch of the one configured local fixture handler. |
| Publish | Separate, explicit human authorization for an exact release. |
| Deploy | Separate, explicit human authorization and environment review. |
| Delete | Separate authority for destructive actions. No agent-facing delete operation. |

Task, project, context, duration and approval constrain the granted actions. A model suggestion, historical approval, stored effect or tool result carries no independent authority. [Human approval gate](HUMAN_APPROVAL_GATE.md)
